# UI 부품 (src/ui/kit)

「올해의 신입」 데모의 공통 UI 부품. 화면은 이 부품을 조립해서 만든다. 색, 글꼴, 간격은 `src/ui/tokens.css`의 변수만 쓴다.

## 방향

| 대상                           | 따르는 것                                                     | 주의                                            |
| ------------------------------ | ------------------------------------------------------------- | ----------------------------------------------- |
| 회사 노트북 앱 (오버레이 워크) | 업무 메신저 구조: 짙은 사이드바, 흰 대화 영역, 초록 주요 버튼 | 실제 서비스의 로고, 이름, 고유 색은 쓰지 않는다 |
| 휴대폰                         | 아이폰 다크 모드 시스템 색과 글자 크기                        | 아이폰 시스템 글꼴 파일은 넣지 않는다           |
| 메모장, 증거 카드              | 종이                                                          | **톤 미정.** 임시 종이색이 기본값으로 들어 있다 |

## 화면 구조

휴대폰이나 노트북을 보는 장면은 실사 손 이미지 위에 UI를 겹친다.

| 순서 (아래에서 위) | 레이어    | 부품                           |
| ------------------ | --------- | ------------------------------ |
| 1                  | 손 이미지 | `PhoneCloseup`                 |
| 2                  | 화면 UI   | `PhoneScreen` + 안에 넣는 부품 |
| 3                  | 화면 빛   | `PhoneCloseup`                 |

흔들림(숨, 떨림)은 1~3을 묶은 전체에 준다. 그래서 UI가 화면 위치에서 어긋나지 않는다.

## 부품

### phone/PhoneCloseup

1인칭 휴대폰 클로즈업 전체.

| prop        | 뜻                                                                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `handSrc`   | 손 이미지 경로. 없으면 어두운 임시 배경                                                                                                     |
| `imageSize` | 손 이미지 원본 크기 `{ width, height }` (px)                                                                                                |
| `screen`    | 손 이미지 속 화면 영역 `{ left, top, right, bottom }` (px). 에셋 담당이 주는 좌표 `.txt`의 값. 모서리 둥글기 `radius`(px)를 함께 줄 수 있다 |
| `shaking`   | 손 떨림 (경계심이 높을 때, 항의 문자가 쏟아질 때)                                                                                           |

```tsx
<PhoneCloseup
  imageSize={{ width: 1280, height: 720 }}
  screen={{ left: 512, top: 108, right: 768, bottom: 612 }}
>
  <PhoneScreen time="09:03" title="메시지">
    {/* 내용 */}
  </PhoneScreen>
</PhoneCloseup>
```

좌표 숫자는 예시다. 손 이미지가 오면 그 값으로 바꾼다.

### phone/PhoneScreen

아이폰 다크 모드 화면 틀. 상태 표시줄, 큰 제목, 뒤로 가기, 본문, 홈 표시줄. 화면 영역 너비를 390pt로 보고 모든 크기를 비례로 맞춘다(`--pt`). 안에 넣는 휴대폰 부품은 이 `--pt`를 쓴다.

| prop     | 뜻                    |
| -------- | --------------------- |
| `time`   | 상태 표시줄 시각      |
| `title`  | 앱 제목(큰 제목)      |
| `onBack` | 있으면 뒤로 가기 표시 |

### phone/Bubble

문자 말풍선. `side`: `in`(받음, 회색) / `out`(보냄, 파랑). `tail`: 묶음의 마지막이면 꼬리.

### phone/Notification

알림 배너. 잠금화면과 화면 위쪽 배너에 같이 쓴다. `app`, `icon`(선택), `time`, `title`(선택), `body`, `onOpen`.

왼쪽에 앱 아이콘, 오른쪽에 굵은 제목과 시각, 그 아래 본문을 보여 준다. 제목이 없으면 `app`이 제목 자리에 나온다. 본문은 4줄까지만 보인다.

### phone/AppIcon

앱 아이콘. 색 있는 둥근 네모 안에 단순한 모양만 그린다(실제 앱의 아이콘은 쓰지 않는다). `kind`: `message`(말풍선) / `bank`(건물). 크기는 감싸는 쪽이 정한다.

### work/WorkMessage

오버레이 워크 메시지 한 줄.

| prop                                | 뜻                                                                             |
| ----------------------------------- | ------------------------------------------------------------------------------ |
| `name`, `time`, `text`, `avatarSrc` | 기본 정보                                                                      |
| `continued`                         | 같은 사람이 연달아 보낸 메시지면 이름과 사진 생략                              |
| `vanishing`, `vanishSec`            | 몇 초 뒤 사라지는 메시지. 아래쪽 줄이 줄어들며 남은 시간을 보여준다 (기본 5초) |
| `deleted`                           | 사라진 뒤 "삭제된 메시지입니다"                                                |

메시지가 실제로 사라지는 타이밍은 엔진이 정하고, 부품은 표시만 한다.

### work/WorkLayout

오버레이 워크 전체 틀. 왼쪽 짙은 사이드바(워크스페이스, 채널, 다이렉트 메시지, 메일) + 오른쪽 본문. 부모 크기에 맞춰 늘어난다(사이드바는 너비의 22%).

| prop         | 뜻                                                                                            |
| ------------ | --------------------------------------------------------------------------------------------- |
| `workspace`  | 워크스페이스 이름 (기본 '오버레이')                                                           |
| `items`      | 사이드바 항목 `{ id, label, kind: 'channel' \| 'dm' \| 'mail', unread? }`. 채널은 `#` 없이 씀 |
| `selectedId` | 선택된 항목 (강조)                                                                            |
| `onSelect`   | 항목을 눌렀을 때. 버튼 id는 `btn_work_open_{id}`                                              |
| `children`   | 오른쪽 본문. 보통 `WorkChannel` 또는 `WorkMail`                                               |

`unread`가 1 이상이면 굵은 글씨와 개수 뱃지를 보인다. 읽음 처리는 부모가 값을 바꿔서 한다.

### work/WorkChannel

대화 영역. 상단 이름 바 + 메시지 목록(`WorkMessage`) + 입력창. 메시지 수가 늘면 맨 아래로 내린다.

| prop       | 뜻                                                   |
| ---------- | ---------------------------------------------------- |
| `name`     | 이름 바 ('# 업무', '박재훈 팀장')                    |
| `topic`    | 이름 옆 짧은 설명                                    |
| `messages` | `WorkMessage`의 prop에 `id`를 더한 목록              |
| `composer` | 아래 입력창. 보통 `WorkComposer`. 없으면 입력창 없음 |

### work/WorkComposer

입력창. `choices`가 있으면 자유 입력 대신 선택지 버튼을 보여 준다.

| prop       | 뜻                                                                           |
| ---------- | ---------------------------------------------------------------------------- |
| `choices`  | `src/data/types.ts`의 `Choice` 목록. 버튼 id는 `btn_work_choose_{choice.id}` |
| `prompt`   | 선택지 위 안내                                                               |
| `onChoose` | 선택지를 눌렀을 때. `effects` 실행은 엔진이 한다                             |
| `onSend`   | 자유 입력 모드에서 보낼 때 (Enter 또는 `btn_work_send`)                      |

### work/WorkMail

메일함. 목록(안 읽음 점, 보낸 사람, 제목과 본문 미리보기, 시간)과 본문 보기.

| prop     | 뜻                                                                   |
| -------- | -------------------------------------------------------------------- |
| `mails`  | `{ id, from, subject, time, body, unread? }` 목록. 위에서부터 보인다 |
| `openId` | 본문을 보고 있는 메일. 없으면 목록                                   |
| `onOpen` | 메일을 눌렀을 때. 버튼 id는 `btn_mail_open_{id}`                     |
| `onBack` | 본문에서 목록으로 (`btn_mail_back`)                                  |

합격 메일을 맨 위에, 같은 문장으로 시작하는 불합격 메일들을 그 아래에 두면 "불합격 메일 위에 합격 메일이 도착한" 장면이 된다. 미리보기 한 줄에 본문 첫머리가 보여서 같은 문장이 반복되는 게 드러난다.

### work/WorkButton

버튼. `variant`: `primary`(채움, `--work-action`) / `secondary`(테두리만). `id`는 `btn_화면_동작` 규칙을 따른다.

### work/WorkPreview

확인용 미리보기. 파일 안의 예시 데이터(합격 메일 1통, 불합격 메일 5통, 팀장 메시지 3개, 선택지 2개)로 위 부품을 조립한다. 게임 대본(`src/data`)과 무관하다.

버튼 id 규칙: `btn_화면_동작`. 오버레이 워크 화면은 `work`, 메일함은 `mail`. 대본의 `interact` 트리거가 이 id를 가리킨다.

### notebook/EvidenceCard

메모장의 증거 카드. 끌어다 빈칸에 놓는다. 끌기가 안 되는 환경을 위해 클릭(또는 Enter, Space)으로 골라 둘 수도 있다.

| prop       | 뜻                                   |
| ---------- | ------------------------------------ |
| `card`     | `src/data/types.ts`의 `EvidenceCard` |
| `selected` | 클릭으로 골라 둔 상태                |
| `used`     | 이미 빈칸에 놓임 (흐리게)            |
| `onSelect` | 클릭했을 때                          |

### notebook/BlankSentence

빈칸 문장. `text`의 `[0]`, `[1]` 자리가 빈칸이다.

| prop              | 뜻                                               |
| ----------------- | ------------------------------------------------ |
| `sentence`        | `src/data/types.ts`의 `BlankSentence`            |
| `cards`           | 증거 카드 id → 카드                              |
| `value`           | 빈칸마다 놓인 카드 id (`null`이면 비어 있음)     |
| `selectedCardId`  | 클릭으로 골라 둔 카드. 빈칸을 누르면 거기 놓인다 |
| `solved`, `wrong` | 정답, 오답 연출                                  |
| `onChange`        | 놓거나 뺄 때                                     |

놓기: 카드를 끌어다 빈칸에 놓거나, 카드 클릭 → 빈칸 클릭. 빼기: 채워진 빈칸 클릭. **정답 판정은 하지 않는다.** 판정과 "연달아 틀리면 그날 밤엔 못 맞춤"은 엔진 담당이다.

## 정해지지 않은 것

- 메모장·증거 카드의 종이 톤 (`--paper` 계열 토큰)
- 메모장 손글씨 글꼴
- 상태 표시줄 아이콘: 지금은 CSS로 그린 단순한 모양. 실제처럼 하려면 아이콘 파일로 교체
- 노트북 화면 부품: 브라우저. 메일함과 메신저 전체 화면은 `work/` 부품으로 만들었다
- Pretendard 글꼴을 저장소에 넣는 방식: 개발자와 결정

## 확인이 필요한 것

이 부품들은 저장소 밖에서 작성되어 타입 검사와 화면 확인을 하지 않았다. 넣은 뒤 `pnpm check`와 `pnpm dev`로 확인한다.
