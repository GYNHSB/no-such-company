# UI 부품 (src/ui/kit)

「올해의 신입」 데모의 공통 UI 부품. 화면은 이 부품을 조립해서 만든다. 색, 글꼴, 간격은 `src/ui/tokens.css`의 변수만 쓴다.

## 방향

| 대상                         | 따르는 것                                                     | 주의                                            |
| ---------------------------- | ------------------------------------------------------------- | ----------------------------------------------- |
| 회사 노트북 앱 (모레온 워크) | 업무 메신저 구조: 짙은 사이드바, 흰 대화 영역, 초록 주요 버튼 | 실제 서비스의 로고, 이름, 고유 색은 쓰지 않는다 |
| 휴대폰                       | 아이폰 다크 모드 시스템 색과 글자 크기                        | 아이폰 시스템 글꼴 파일은 넣지 않는다           |
| 메모장, 증거 카드            | 종이                                                          | **톤 미정.** 임시 종이색이 기본값으로 들어 있다 |

## 화면 구조

휴대폰이나 노트북을 보는 장면은 실사 손 이미지 위에 UI를 겹친다.

| 순서 (아래에서 위) | 레이어    | 부품                           |
| ------------------ | --------- | ------------------------------ |
| 1                  | 손 이미지 | `PhoneCloseup`                 |
| 2                  | 화면 UI   | `PhoneScreen` + 안에 넣는 부품 |
| 3                  | 화면 빛   | `PhoneCloseup`                 |

흔들림(숨, 떨림)은 1~3을 묶은 전체에 준다. 그래서 UI가 화면 위치에서 어긋나지 않는다.

## 부품

### phone/PhoneCloseup

1인칭 휴대폰 클로즈업 전체.

| prop        | 뜻                                                                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `handSrc`   | 손 이미지 경로. 없으면 어두운 임시 배경                                                                                                     |
| `imageSize` | 손 이미지 원본 크기 `{ width, height }` (px)                                                                                                |
| `screen`    | 손 이미지 속 화면 영역 `{ left, top, right, bottom }` (px). 에셋 담당이 주는 좌표 `.txt`의 값. 모서리 둥글기 `radius`(px)를 함께 줄 수 있다 |
| `shaking`   | 손 떨림 (경계심이 높을 때, 항의 문자가 쏟아질 때)                                                                                           |

```tsx
<PhoneCloseup
  imageSize={{ width: 1280, height: 720 }}
  screen={{ left: 512, top: 108, right: 768, bottom: 612 }}
>
  <PhoneScreen time="09:03" title="메시지">
    {/* 내용 */}
  </PhoneScreen>
</PhoneCloseup>
```

좌표 숫자는 예시다. 손 이미지가 오면 그 값으로 바꾼다.

### phone/PhoneScreen

아이폰 다크 모드 화면 틀. 상태 표시줄, 큰 제목, 뒤로 가기, 본문, 홈 표시줄. 화면 영역 너비를 390pt로 보고 모든 크기를 비례로 맞춘다(`--pt`). 안에 넣는 휴대폰 부품은 이 `--pt`를 쓴다.

| prop          | 뜻                                                                |
| ------------- | ----------------------------------------------------------------- |
| `time`        | 상태 표시줄 시각                                                  |
| `statusLabel` | 상태 표시줄 왼쪽에 시각 대신 보여 줄 글(잠금 화면의 통신사 이름)  |
| `title`       | 앱 제목(큰 제목)                                                  |
| `onBack`      | 있으면 뒤로 가기 표시                                             |
| `onHome`      | 아래 막대를 눌렀을 때. 있으면 막대가 홈 화면으로 가는 단추가 된다 |

### phone/Bubble

문자 말풍선. `side`: `in`(받음, 회색) / `out`(보냄, 파랑). `tail`: 묶음의 마지막이면 꼬리.

### phone/Notification

알림 배너. 잠금화면과 화면 위쪽 배너에 같이 쓴다. `app`, `icon`(선택), `time`, `title`(선택), `body`, `onOpen`.

왼쪽에 앱 아이콘, 오른쪽에 굵은 제목과 시각, 그 아래 본문을 보여 준다. 제목이 없으면 `app`이 제목 자리에 나온다. 본문은 4줄까지만 보인다.

### phone/PhoneNav

휴대폰 앱 화면 위쪽 줄. 왼쪽에 뒤로 가기, 가운데에 내용(`children`), 오른쪽에 단추(`right`), 아래에 아이폰식 큰 제목(`title`)을 둔다. `PhoneScreen` 안에 넣는다.

- `onBack`이 있으면 뒤로 가기 단추를 그린다. `backLabel`은 화살표 옆의 글(돌아갈 화면 이름)이고, 화살표만 둘 때는 `backAriaLabel`로 읽을 이름을 준다.
- 내용이 없어도 줄 높이(44pt)는 차지한다. 그래서 앱마다 큰 제목이 같은 높이에 온다.
- 뒤로 가기 색은 감싸는 쪽에서 `--phone-accent`로 바꾼다(메모 앱은 주황). 정하지 않으면 파랑이다.

### phone/AppIcon

앱 아이콘. 색 있는 둥근 네모 안에 단순한 모양만 그린다(실제 앱의 아이콘은 쓰지 않는다). `kind`: `message`(말풍선) / `bank`(건물) / `notes`(줄 그어진 종이) / `photos`(해와 산) / `sns`(겹쳐 놓은 사진 두 장). 크기는 감싸는 쪽이 정한다.

### work/WorkMessage

모레온 워크 메시지 한 줄.

| prop                                | 뜻                                                                             |
| ----------------------------------- | ------------------------------------------------------------------------------ |
| `name`, `time`, `text`, `avatarSrc` | 기본 정보                                                                      |
| `continued`                         | 같은 사람이 연달아 보낸 메시지면 이름과 사진 생략                              |
| `vanishing`, `vanishSec`            | 몇 초 뒤 사라지는 메시지. 아래쪽 줄이 줄어들며 남은 시간을 보여준다 (기본 5초) |
| `deleted`                           | 사라진 뒤 "삭제된 메시지입니다"                                                |

메시지가 실제로 사라지는 타이밍은 엔진이 정하고, 부품은 표시만 한다.

### work/WorkLayout

모레온 워크 전체 틀. 왼쪽 짙은 사이드바(워크스페이스, 채널, 다이렉트 메시지, 메일) + 오른쪽 본문. 부모 크기에 맞춰 늘어난다(사이드바는 너비의 22%).

| prop         | 뜻                                                                                            |
| ------------ | --------------------------------------------------------------------------------------------- |
| `workspace`  | 워크스페이스 이름 (기본 '모레온')                                                             |
| `items`      | 사이드바 항목 `{ id, label, kind: 'channel' \| 'dm' \| 'mail', unread? }`. 채널은 `#` 없이 씀 |
| `selectedId` | 선택된 항목 (강조)                                                                            |
| `onSelect`   | 항목을 눌렀을 때. 버튼 id는 `btn_work_open_{id}`                                              |
| `children`   | 오른쪽 본문. 보통 `WorkChannel` 또는 `WorkMail`                                               |

`unread`가 1 이상이면 굵은 글씨와 개수 뱃지를 보인다. 읽음 처리는 부모가 값을 바꿔서 한다.

### work/WorkChannel

대화 영역. 상단 이름 바 + 메시지 목록(`WorkMessage`) + 입력창. 메시지 수가 늘면 맨 아래로 내린다.

| prop       | 뜻                                                   |
| ---------- | ---------------------------------------------------- |
| `name`     | 이름 바 ('# 업무', '김아영 팀장')                    |
| `topic`    | 이름 옆 짧은 설명                                    |
| `messages` | `WorkMessage`의 prop에 `id`를 더한 목록              |
| `composer` | 아래 입력창. 보통 `WorkComposer`. 없으면 입력창 없음 |

### work/WorkComposer

입력창. `choices`가 있으면 자유 입력 대신 선택지 버튼을 보여 준다.

| prop       | 뜻                                                                           |
| ---------- | ---------------------------------------------------------------------------- |
| `choices`  | `src/data/types.ts`의 `Choice` 목록. 버튼 id는 `btn_work_choose_{choice.id}` |
| `prompt`   | 선택지 위 안내                                                               |
| `onChoose` | 선택지를 눌렀을 때. `effects` 실행은 엔진이 한다                             |
| `onSend`   | 자유 입력 모드에서 보낼 때 (Enter 또는 `btn_work_send`)                      |

### work/WorkMail

메일함. 목록(안 읽음 점, 보낸 사람, 제목과 본문 미리보기, 시간)과 본문 보기.

| prop     | 뜻                                                                   |
| -------- | -------------------------------------------------------------------- |
| `mails`  | `{ id, from, subject, time, body, unread? }` 목록. 위에서부터 보인다 |
| `openId` | 본문을 보고 있는 메일. 없으면 목록                                   |
| `onOpen` | 메일을 눌렀을 때. 버튼 id는 `btn_mail_open_{id}`                     |
| `onBack` | 본문에서 목록으로 (`btn_mail_back`)                                  |

합격 메일을 맨 위에, 같은 문장으로 시작하는 불합격 메일들을 그 아래에 두면 "불합격 메일 위에 합격 메일이 도착한" 장면이 된다. 미리보기 한 줄에 본문 첫머리가 보여서 같은 문장이 반복되는 게 드러난다.

### work/WorkButton

버튼. `variant`: `primary`(채움, `--work-action`) / `secondary`(테두리만). `id`는 `btn_화면_동작` 규칙을 따른다.

### work/WorkPreview

확인용 미리보기. 파일 안의 예시 데이터(합격 메일 1통, 불합격 메일 5통, 팀장 메시지 3개, 선택지 2개)로 위 부품을 조립한다. 게임 대본(`src/data`)과 무관하다.

버튼 id 규칙: `btn_화면_동작`. 모레온 워크 화면은 `work`, 메일함은 `mail`. 대본의 `interact` 트리거가 이 id를 가리킨다.

### notebook/EvidenceCard

메모장의 증거 카드. 끌어다 빈칸에 놓는다. 끌기가 안 되는 환경을 위해 클릭(또는 Enter, Space)으로 골라 둘 수도 있다.

| prop       | 뜻                                   |
| ---------- | ------------------------------------ |
| `card`     | `src/data/types.ts`의 `EvidenceCard` |
| `selected` | 클릭으로 골라 둔 상태                |
| `used`     | 이미 빈칸에 놓임 (흐리게)            |
| `onSelect` | 클릭했을 때                          |

### notebook/BlankSentence

빈칸 문장. `text`의 `[0]`, `[1]` 자리가 빈칸이다.

| prop              | 뜻                                               |
| ----------------- | ------------------------------------------------ |
| `sentence`        | `src/data/types.ts`의 `BlankSentence`            |
| `cards`           | 증거 카드 id → 카드                              |
| `value`           | 빈칸마다 놓인 카드 id (`null`이면 비어 있음)     |
| `selectedCardId`  | 클릭으로 골라 둔 카드. 빈칸을 누르면 거기 놓인다 |
| `solved`, `wrong` | 정답, 오답 연출                                  |
| `onChange`        | 놓거나 뺄 때                                     |

놓기: 카드를 끌어다 빈칸에 놓거나, 카드 클릭 → 빈칸 클릭. 빼기: 채워진 빈칸 클릭. **정답 판정은 하지 않는다.** 판정과 "연달아 틀리면 그날 밤엔 못 맞춤"은 엔진 담당이다.

## 게임 공통 화면 (src/ui/screens/common)

3D 방, 휴대폰, 노트북 어느 장면에서나 함께 쓰는 화면이다. 상위 이슈 #36.

공통 규칙:

- 모두 `position: absolute`라서 화면 전체를 덮는 부모 안에 둔다. 위에 보여야 하는 것일수록 아래쪽 코드에 둔다. 순서(아래 → 위): 3D 방, 휴대폰·노트북 화면, 우편물·메모장·선택지, 혼잣말 창, 왼쪽 위 날짜, 날짜 카드, 엔딩
- 정답 판정, 경계심, 엔딩 판정은 하지 않는다. 엔진이 정한 값을 받아 보여 주고, 누른 결과만 알린다.
- 플레이어 이름은 자료의 `{name}` 자리에 글자로 넣는다. 이미지에 넣지 않는다.
- 움직임 줄이기 설정이면 미끄러지는 움직임 없이 나타났다 사라진다.
- 확인: 개발 서버 `?sandbox=hyeopseong`의 오른쪽 위 패널

### common/GuideBanner

휴대폰 알림 모양의 안내 문구(대본의 [안내]). 화면 위에서 내려와 6초 머문 뒤 올라가고, 그 자리에 작은 종 손잡이가 남는다. 손잡이를 누르거나 G를 누르면 다시 내려온다. 문구가 바뀌면 새 알림이 내려온다.

| prop     | 뜻                                                             |
| -------- | -------------------------------------------------------------- |
| `text`   | 안내 문구. 자료의 `goal` 효과 문구를 넣는다. `null`이면 감춘다 |
| `holdMs` | 머무는 시간(ms). 기본 6000. `null`이면 계속 떠 있다            |

```tsx
<GuideBanner text="책상 위 노트북을 확인하세요." />
```

### common/DateCard, DayBadge, dayLabel

날짜 카드: 장면이 검게 가라앉고 "2일차 / 입사 3주 차"가 떠올랐다가(약 3.6초), "2일차"가 왼쪽 위로 날아가 `DayBadge` 자리에 내려앉는다. "그날 오후"처럼 날짜가 아닌 글은 날아가지 않는다. `DayBadge`는 왼쪽 위에 계속 남는 날짜와 깜빡이는 초록 점(웹캠 불빛)이다.

| 부품       | prop                                                                |
| ---------- | ------------------------------------------------------------------- |
| `DateCard` | `text`("2일차 · 입사 3주 차" 또는 "그날 오후"), `onDone`(끝났을 때) |
| `DayBadge` | `text`("2일차", `null`이면 감춤)                                    |
| `dayLabel` | `dayLabel(info)` → "2일차 · 입사 3주 차" (자료의 `DayInfo`)         |

카드가 시작되면 `DayBadge`는 감추고, `onDone`에서 새 날짜로 띄운다(날아오는 동안 두 개가 보이지 않게). 둘은 같은 전체 화면 칸 안에 둔다.

### common/ChoiceMenu

화면 아래쪽 선택지. 누르거나 숫자 키 1, 2, 3으로 고른다. 고른 줄이 잠깐 밝아진 뒤 알린다.

| prop       | 뜻                                                    |
| ---------- | ----------------------------------------------------- |
| `prompt`   | 질문("팀장에게 뭐라고 답할까")                        |
| `choices`  | 자료의 `Choice`(id, label). 화면에는 label만 쓴다     |
| `onChoose` | 고른 id. 경계심과 기록은 엔진이 바꾸고, 부모가 닫는다 |

엔진에 바라는 것: 대사(따옴표 있는 선택지)를 고르면 혼잣말 창에 그 대사를 한 번 더 보낸다. "서명한다"는 서명 패드를, "찍어서 보낸다"·"카메라를 보고 읽는다"는 웹캠 켜기를 잇는다.

### common/MailCloseup

현관 우편물 클로즈업. `envelope`가 있으면 겉봉(보낸 곳, 등기 도장, 바코드, 받는 주소와 이름)부터 보여 주고, "열어 보기"를 누르면 속 서류가 나온다. 서류 첫 줄에 마침표가 없으면 제목으로, "이름: 값" 줄은 표 칸으로 쓴다.

| prop       | 뜻                                                                 |
| ---------- | ------------------------------------------------------------------ |
| `message`  | 자료의 `post` 메시지(from, body)                                   |
| `name`     | 플레이어 이름                                                      |
| `envelope` | 겉봉(from, address, trackingNo). 자료 양식에 칸이 없어 따로 받는다 |
| `onStage`  | 겉봉/서류 중 지금 보는 것. 혼잣말을 이 순간에 맞춘다               |
| `onClose`  | 내려놓기 버튼, Esc                                                 |

### common/Notebook

펼친 수첩 모양의 메모장. 왼쪽 쪽은 모은 증거 카드(`kit/notebook/EvidenceCard`), 오른쪽 쪽은 빈칸 문장(`kit/notebook/BlankSentence`)과 "맞춰 보기" 버튼이다.

| prop        | 뜻                                                                                   |
| ----------- | ------------------------------------------------------------------------------------ |
| `cards`     | 모은 증거 카드                                                                       |
| `sentences` | 오늘까지 열린 빈칸 문장                                                              |
| `status`    | 문장 id → `solved`(맞음), `wrong`(방금 틀림, 흔들림), `locked`(오늘 밤엔 더 못 맞춤) |
| `onSubmit`  | 문장 id와 빈칸 순서대로 놓은 카드 id. 판정은 엔진이 한다                             |
| `onClose`   | 덮기 버튼, Esc                                                                       |

### common/EndingScreen, endingText

엔딩 장면과 결과 카드. 검은 화면에 엔딩 글이 한 줄씩 나오고(클릭하면 건너뜀), 인사 기록 카드 모양의 결과 카드가 올라와 결말 도장이 찍힌다. 글은 `endingText.ts`에 있다(초안, 대본 담당이 고친다).

| prop        | 뜻                                                                      |
| ----------- | ----------------------------------------------------------------------- |
| `ending`    | 엔진의 판정(`accomplice`, `scapegoat`, `escaped`, `safe`)               |
| `name`      | 플레이어 이름                                                           |
| `record`    | 근무 기간, 모은 증거, 맞춘 문장, 서명, 신고, 경계심 최고(엔진이 모은다) |
| `onRestart` | 처음부터 다시                                                           |

### common/Pocket, SignaturePad

- `Pocket`: 오른쪽 아래 소지품 칸. `items`(id, label, keyLabel, icon, onOpen). 물건이 없으면 안 보인다. 휴대폰 그림은 `PhoneIcon`.
- `SignaturePad`: 마우스로 그리는 서명란. 다시 쓰기, 서명 완료. `onSign(image)`로 그린 서명을 투명 PNG 주소로 넘긴다. 마우스를 못 쓰면 Tab으로 고른 뒤 Enter. 5일차 취임식(`laptop/InaugurationCall`)의 서류 아래 자리(children)에 넣어 쓴다.

## 정해지지 않은 것

- 메모장·증거 카드의 종이 톤 (`--paper` 계열 토큰)
- 메모장 손글씨 글꼴
- 상태 표시줄 아이콘: 지금은 CSS로 그린 단순한 모양. 실제처럼 하려면 아이콘 파일로 교체
- 노트북 화면 부품: 브라우저. 메일함과 메신저 전체 화면은 `work/` 부품으로 만들었다
- Pretendard 글꼴을 저장소에 넣는 방식: 개발자와 결정

## 확인이 필요한 것

이 부품들은 저장소 밖에서 작성되어 타입 검사와 화면 확인을 하지 않았다. 넣은 뒤 `pnpm check`와 `pnpm dev`로 확인한다.
