# 올해의 신입: 데모 대본 (읽는 용, v1-2)

- 작성일: 2026-11-26
- v1-2에서 바뀐 것: 1일차를 넋두리로 시작하게 다시 썼고, 장면마다 안내 문구와 주인공의 혼잣말을 넣었다.
- 이 파일은 읽고 고칠 곳을 표시하기 위한 사본이다.
  실제 게임이 읽는 원본(`src/data/days/day1.ts` ~ `day5.ts`)에는 아직 반영하지 않았다.
- `○○`는 플레이어가 입력한 이름이 들어가는 자리다.

**표시**

- **[안내]** 화면 위에 뜨는 안내 문구. 다음에 무엇을 하면 되는지 알려 준다.
- **[혼잣말]** 화면 아래 독백 창에 한 줄씩 나오는 주인공의 말. 한 줄이 한 번에 나온다.
- **[메일] [메신저] [문자] [은행] [우편] [SNS] [블라블라]** 화면 속에 도착하는 글.

---

## 시작 화면

**이름 입력**

- 화면 문구: 이름을 입력해 주세요.
- 작은 글씨: 이 이름은 게임 속 메일, 우편, 문자에 그대로 쓰여요. 브라우저 밖으로는 나가지 않아요.
- 버튼: 시작하기

**조작 안내 (이야기 설명은 하지 않는다)**

- 화면을 클릭하면 마우스로 둘러볼 수 있어요.
- W A S D로 걸어요.
- 가운데 점을 물건에 맞추고 클릭하면 살펴볼 수 있어요.

## 확인이 필요한 곳

- **1일차 메일 순서를 바꿨다.**
  이내 님의 견본은 "최종 합격 메일 → 면접 앱 → 면접" 순서다.
  합격한 뒤에 면접을 보는 순서가 어색해서 "서류 합격 문자·메일 → 면접 앱 → 면접 → 최종 합격" 순서로 썼다.
  GDD는 면접을 "회상"으로 처리했으므로, 어느 쪽으로 갈지 작가와 이내 님 확인이 필요하다.
- **1일차에 첫 업무 장면(장면 9)을 넣었다.**
  대본 가이드의 1일차 안내문 문장("원금 100% 보장, 매월 8% 확정 수익")이 여기 들어간다.
- **혼잣말을 넣을 칸이 양식에 없다.**
  `types.ts`는 개발자 승인 없이 바꿀 수 없어서, 혼잣말을 자료에 넣으려면 개발자에게 칸을 요청해야 한다.
  안내 문구는 지금 양식의 "목표 문구" 칸에 넣을 수 있다.
- 3일차 "계좌 3개"와 5일차 "관리자 계정을 휴대폰으로 확인"은 문서에 없던 장면이다.
- 가상 이름(주식회사 다온링크, 주식회사 한빛웍스, 도경석, 변하늘, 마동현)이 실제 회사나 인물과 겹치지 않는지 확인하지 못했다.
- 주인공 나이(서른 살)는 "6년 차 취업준비생"에서 짐작해 넣은 것이다.
