## 2026-11-27 휴대폰 잠금 화면 알림

- 맡긴 일: 휴대폰 잠금 화면 알림 화면(#49) 만들기
- 사용한 AI: Claude Code (Fable 5.2)
- 요청 내용: 직접 적은 작업 규칙을 먼저 검토하게 하고, 화면별 계획을 확인한 뒤 #49부터 만들게 함. 테스트 페이지에서 화면을 보면서 손 이미지 붙이기, 모서리 맞추기, 실제 날짜와 요일, 배경 화면, 반투명 알림, 아이폰식 알림 배치, 흐르는 시계, 통신망 이름을 차례로 요청함
- 결과: 잠금 화면(`src/ui/screens/phone/LockScreen`)과 시계 훅, kit 부품 `AppIcon` 추가, `PhoneCloseup`·`PhoneScreen`·`Notification` 변경, 테스트 페이지에서 세 장면 확인, Draft PR #77
- 사람이 고친 것: 시계 위 한 줄을 AI가 넣은 "N일차 · 입사 N주 차"에서 실제 날짜로 바꾸고, 요일을 대본의 고객 명단 요일에 맞추게 함. 화면 모서리가 목업과 안 맞는 것, 화면이 너무 검은 것, 두 시계의 글꼴이 다른 것을 짚어 고치게 함. AI가 추천한 통신사 이름 "도담모바일"을 통신망 이름으로 바꾸게 함. 커밋 메시지에서 이름을 빼게 함
- 관련 이슈/PR: #35, #49, #77
