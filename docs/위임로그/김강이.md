## 2026-11-28 방 안 조작 바꾸기와 의자 앉기

- 맡긴 일: 방 안에서 물건을 쉽게 고르게 하고, 화면에 단추를 넣고, 의자에 앉을 수 있게 하기(#125)
- 사용한 AI: Claude Code (Fable 5.2)
- 요청 내용: 마우스로 클릭하면서 시점도 같이 움직여야 하는 것이 불편하다고 알리고 개선점을 제안받음. 만든 것을 직접 해 보면서 차례로 고치게 함: 끌어서 돌리는 것이 불편하니 A/D로 몸을 돌리게, 노트북을 닫은 뒤 다시 클릭해야 하는 것과 누운 채 Esc가 안 먹는 것을 고치게, 의자에 앉을 수 있게, 물건이 너무 멀리서 넓게 잡히지 않게, 커서를 잠그지 않게, 커서를 따라 시점이 움직이게, 화면 가운데 점과 커서를 하나로 합치게 함. 방식을 바꾸기 전에는 장단점을 먼저 듣고 고름. 손 이미지는 소매가 잘린 맨 아래만 가리게 다시 맞추게 함
- 결과: 커서를 잠그지 않는 조작(A/D로 돌기, 커서 쪽으로 고개 기울이기 `CursorLook`, 커서 근처 물건을 클릭이나 E로 고르기), 의자에 앉기(`gameStore`의 `seat`, `closeView`), 소지품 칸과 돌아가기 단추, 커서 옆 물건 안내, 조작 안내, 혼잣말 창 자리, 손 이미지 내리는 정도 조정, Draft PR #128
- 사람이 고친 것: AI가 처음 만든 끌어서 둘러보기를 불편하다며 버리게 함. AI가 되살린 커서 잠금 방식은 Esc와 겹치고 노트북을 닫은 뒤 흐름이 어색하다는 것을 직접 해 보고 짚어, 커서를 잠그지 않는 쪽으로 바꾸게 함. AI가 넣은 화면 가운데 점은 커서와 따로 놀아 불편하다며 커서 하나로 합치게 함. AI가 3m, 29도로 잡은 고르는 범위를 너무 넓다며 줄이게 함. AI가 손 이미지를 소매가 다 가려지게 내린 것을, 소매는 보이고 잘린 아래쪽 끝만 가리는 것이라고 바로잡음
- 관련 이슈/PR: #35, #89, #122, #124, #125, #127, #128
