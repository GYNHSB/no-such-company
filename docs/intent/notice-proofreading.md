# 안내문 맞춤법 검수 업무 화면 (#41)

2026-11-27에 인터뷰로 확정한 의도예요.

## 목표

- 메신저의 검수 요청 카드를 누르면 열리는 안내문 검수 화면을 만들어요.
- 플레이어가 틀린 낱말을 누르고, 후보 세 개 중 바른 표기를 골라 고친 뒤 "검수 완료"를 눌러요.
- 사기 문구를 제 손으로 고치게 해서, 4일차 혼잣말 "내가 맞춤법을 고친 문장이다"가 성립하게 해요.
- 데모 압축판의 1일차 장면 9, 2일차 장면 3, 3일차 장면 3에 쓰여요.

## 완료 기준

- 세 문장이 오타를 하나씩 담고 나오고, `{name}`은 입력한 이름으로 바뀌어요.
- 오타를 고쳐야만 "검수 완료"가 켜지고, 누르면 `onDone`으로 알려요.
- 메신저 카드에도 오타가 든 문장이 보여요.
- 검수를 마친 카드에는 "완료" 라벨이 붙어요.
- 테스트 페이지(`?sandbox=seongbeom`)에서 세 날 모두 해 볼 수 있어요.
