# no-such-company

원티드 AI 네이티브 캠프 2기 2차 프로젝트

## 명령어

Node 26, pnpm 12를 써요. (`.nvmrc`, `package.json`의 `packageManager`)

| 명령어         | 하는 일                                          |
| -------------- | ------------------------------------------------ |
| `pnpm install` | 의존성 설치                                      |
| `pnpm dev`     | 개발 서버 실행                                   |
| `pnpm check`   | 타입 검사, 린트, 포맷 검사, 단위 테스트를 한번에 |
| `pnpm format`  | Prettier로 전체 포맷 적용                        |
| `pnpm build`   | 빌드                                             |
| `pnpm e2e`     | Playwright E2E 테스트                            |
