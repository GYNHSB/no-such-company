# 프롬프트

> 아직 뼈대예요. 실제로 쓴 프롬프트를 파일로 추가해야 해요.

팀이 AI에게 쓴 프롬프트와, 고쳐 쓴 이유를 남기는 폴더예요.

## 쓰는 법

- 프롬프트 하나에 파일 하나를 만들어요. 예: `prompts/01-게임-기획.md`
- 처음 쓴 프롬프트(v1)와 고친 프롬프트(v2)를 모두 남기고, **왜 바꿨는지**를 꼭 적어요.

```markdown
# 프롬프트 이름

- 어디에 썼나요:
- 쓴 사람:

## v1

(처음 쓴 프롬프트)

### 결과와 아쉬운 점

## v2

(고친 프롬프트)

### v1에서 바꾼 이유

### 결과
```
