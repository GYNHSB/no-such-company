# 입사 서류를 메신저에서 첨부하기

- 어디에 썼나요: 입사 서류 올리기 화면을 만들 때
- 쓴 사람: 임성범

## v1

로컬 브랜치 지우고 #39 진행해

### 결과와 아쉬운 점

이슈 내용대로, 서류 네 가지를 한 줄씩 보여 주고 "올리기"와 "제출하기"를 누르는 화면이 따로 생겼어요. 대화 아래의 임시 버튼으로 열어야 했어요.

## v2

슬랙처럼 메시지 입력창에 파일 첨부를 할 수 있도록 하자. 그리고 첨부 방식은 슬랙처럼 파일 finder가 열려서 첨부하거나, 파일 드래그 앤 드롭으로 첨부할 수 있도록.

### v1에서 바꾼 이유

따로 뜨는 화면 대신, 업무 메신저처럼 메시지 입력창에서 파일을 첨부하게 하려고 바꿨어요.

### 결과

입력창의 + 버튼으로 파일 선택 창을 열어 서류를 고르거나, 입력창으로 끌어다 놓아 첨부해요. 파일 선택 창은 게임 속 창이에요. 이슈에 "실제 파일 선택 창을 띄우지 않고 플레이어의 파일을 받지 않는다"가 있어서, 운영체제의 파일 창은 열지 않게 했어요.
