# 메일함을 웹 메일처럼 만들기

- 어디에 썼나요: 1일차 메일함 화면의 모양을 다듬을 때
- 쓴 사람: 임성범

## v1

gmail과 유사한 UI로 만들어줘. 왼쪽에 사이드바 메뉴 만들어 주고

### 결과와 아쉬운 점

왼쪽 메뉴, 검색창, 체크박스와 별표가 있는 목록이 생겼어요. 메뉴에 아이콘이 없었고, 기호가 글꼴 문자라 운영체제마다 모양이 달라질 수 있었어요.

## v2

메뉴 항목 아이콘 추가하고, 기호는 운영체제가 달라도 동일하게 보일 수 있도록 통일해줘

### v1에서 바꾼 이유

AI가 보고한 두 가지 한계(아이콘 없음, 기호 모양 차이)를 없애려고 바꿨어요.

### 결과

메뉴 아이콘이 생기고 기호가 모두 SVG로 바뀌었어요.
